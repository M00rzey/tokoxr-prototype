# TokoXR Prototype

A responsive, high fidelity alpha prototype for the TokoXR HCI assignment. It covers all five Q1 solutions and includes a buyer discovery flow, seller tools, and an order overview.

## Open the prototype

Open `index.html` in a modern browser. The prototype is static and has no build step or account setup.

## Screens and interactions

- **Discover:** handmade product cards, feature entry points, and camera privacy note.
- **AR Try-in-Space (S1):** sample room, seller-confirmed dimensions, and indicative handmade preview.
- **AR Custom Builder (S2):** modular flower choices, colours, stem count, estimated price, and message card.
- **3D Scan Studio (S3):** guided capture, simulated coverage and scan queue, quality guidance, dimensions, and bilingual help.
- **Virtual Bazaar (S4):** themed market, maker booths, and a simulated immersive-mode introduction.
- **Gift Advisor (S5):** occasion, budget, recipient, and space preferences with catalogue-only sample recommendations.
- **My orders:** seller order summary with sample buyer details.

The XR camera, 3D reconstruction, AI service, chat, authentication, order backend, and payment service are represented by demo interactions. The prototype does not request camera access, upload images, store personal data, or process payments. The AR preview uses an illustrative sample room and flower artwork, not production 3D assets.

## Publish as a static site

The folder can be added to a GitHub repository and served with GitHub Pages. No server or database is required for this alpha.
